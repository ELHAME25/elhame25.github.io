# حالة تأسيس الحسابات
التسجيل الجديد: الاسم والإيميل ثم OTP. الدخول: الإيميل ثم OTP. لا كلمة مرور ولا جوال.

تم بناء صفحات التسجيل والدخول والتحقق وإعادة الإرسال وتعديل الإيميل والخروج، والتحقق الحقيقي عبر Supabase Auth REST API. لا رمز ثابت أو محاكاة نجاح.

المطلوب لتفعيل الحسابات:
1. إنشاء مشروع Supabase تحت حساب المالك وربط مزود SMTP مناسب.
2. تفعيل Email OTP وقالب Magic Link الذي يتضمن {{ .Token }}، وضبط صلاحية الرمز ومحاولاته.
3. وضع رابط المشروع والمفتاح العام publishable في auth-config.json. ممنوع وضع service_role أو مفتاح سري فيه.
4. تطبيق schema.sql، والتحقق من عزل مستخدمين مختلفين قبل تفعيل المزامنة.
5. ربط قراءة وكتابة الجداول بالواجهة. هذا الربط لم يُنفذ بعد، والنسخة الحالية محلية فقط، وهو مذكور للمستخدم.
6. مراجعة شروط الاستخدام والخصوصية قبل فتح التسجيل للجمهور.

لا يرسل الموقع أي بريد قبل ضبط الإعدادات. تظهر رسالة واضحة بأن الخدمة غير مفعلة.
الملاحظات الصوتية والذكاء الاصطناعي والدعوات الجماعية ليست ضمن الخدمات المفعلة حاليًا.
