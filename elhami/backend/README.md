# تشغيل وكيل إلهامي
Node.js 22 أو أحدث. بلا حزم خارجية.

متغيرات الخادم السرية:
- OPENAI_API_KEY: مفتاح OpenAI API. لا يوضع في المتصفح أو GitHub.
- OPENAI_MODEL: اسم نموذج يدعم Responses API ومتاح لحسابك.
- ELHAMI_ACCESS_TOKEN: رمز عشوائي قوي للتجربة الخاصة، مختلف عن مفتاح OpenAI.
- ELHAMI_ALLOWED_ORIGIN: أصل الموقع حرفيًا، مثل https://elhame25.github.io
- PORT: اختياري، الافتراضي 8787.

التشغيل: node server.mjs
يجب نشره خلف HTTPS، ثم وضع عنوان الخادم في إعدادات الوكيل داخل الموقع.
هذا خادم تجريبي لمجموعة موثوقة؛ لا يُفتح للجمهور قبل إضافة تحقق حسابات وحصص استهلاك موزعة. رمز التجربة ليس بديلًا عن حسابات المستخدمين.
لا يكتب المحتوى في ملفات أو سجلات، ويرسل store:false؛ هذا لا يضمن انعدام احتفاظ مزود النموذج بالبيانات. راجع سياساته قبل الوعد للمستخدم.
لا يقدم صوتًا جماعيًا أو تفريغًا مستمرًا بعد. تمرّر الواجهة النص الذي يوافق المستخدم على إرساله.
